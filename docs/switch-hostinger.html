Gaber: change the DNS when Kevin asks

  1. Kevin sends you the A record address from Hostinger, a number like 123.45.67.89. Use only that one.
  2. Log in to Porkbun and open DNS for cityoffighters.com.
  3. Screenshot the current records. You need them to undo this.
  4. Delete these four A records: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
  5. Add one record: Type A, Host empty, Target the Hostinger address, TTL 600.
  6. Only if Kevin gives a different value for www, change that CNAME too. Don’t change the nameservers.
  7. Tell Kevin it’s done. It usually takes minutes but can take up to 24 hours. Kevin then turns on SSL and Force HTTPS. A security warning for a short time is normal.

to undo: in Porkbun delete the Hostinger record and add the four GitHub records back. This only works while GitHub Pages is still on, so nobody turns it off until every check passes.

Gaber: set up the streaming PC

Do this after the checks above, using the OBS Manual for the details.

  1. Install OBS and connect Twitch (Manual sections 1 and 5).
  2. In OBS, turn on Tools → WebSocket Server Settings → Enable WebSocket server.
  3. Add a Browser source with https://cityoffighters.com/overlay.html, 1920 × 1080, above the game. Never use the old github.io address.
  4. Add the game (capture card or screen).
  5. Install the PC app from Settings → Get the apps at cityoffighters.com and log in with the new password.
  6. Open the Stream tab (Ctrl + 3). It connects to OBS by itself. Choose the Game screen and build the Coming Up screen.
  7. On a private or unlisted stream, test Go live and End stream.
  8. During a Tekken loading screen, check that the Stream tab shows at least 98% dark.

Keep the Stream tab open during every tournament. Black-screen cards, Go live and End stream need it.
