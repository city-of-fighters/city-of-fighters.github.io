What you do when moving · 6 November 2026

Switch to Hostinger

What the owner of cityoffighters.com needs to do when the site moves from GitHub to Hostinger. Your partner’s Claude does the technical side from DEPLOY-HOSTINGER.md in the GitHub repo.

the address stays cityoffighters.com, so the OBS link and the installed apps keep working. Everyone has to log in again, because the database is new. Iron Fist Academy stays in the old Supabase project.

Before you start

☐Your partner has a Hostinger plan that supports Git deployment (web or cloud hosting, not agency hosting)
☐Your partner has access to the GitHub repo
☐You can log in to Porkbun
☐No tournament or stream is running or coming up that day

don’t buy the domain again on Hostinger, and don’t change the Porkbun nameservers. You only change the records in Step 2.

First: the new database

  1. Create the new Supabase account and a new project. Use an email someone reads.
  2. Decide what to do with your data. The new database starts empty, with the 6 original sponsors. Test players, photos and past tournaments don’t come across. The calendar refills from start.gg.
  3. In the new project, open the SQL Editor, paste all of supabase/city-of-fighters.sql and press Run. Then set the admin password with the line in DEPLOY-HOSTINGER.md.
  4. In its Edge Functions → Secrets, add GMAIL_USER, GMAIL_APP_PASSWORD, SGG_CLIENT_ID and SGG_CLIENT_SECRET.
  5. Deploy cof-winner-email and cof-startgg, each with Verify JWT with legacy secret off.
  6. Give your partner the new project’s URL and publishable key. Never share the service or secret key.

After the switch, paste the start.gg token in Settings again. Test mode starts on.

Step 1: your partner prepares Hostinger

He tells his Claude:

Clone city-of-fighters/city-of-fighters.github.io, read DEPLOY-HOSTINGER.md, and follow it step by step. Ask me before anything it says to ask about.

Wait until he confirms that the site works on Hostinger’s temporary address. Your live site isn’t touched in this step.

Step 2: you change the DNS records

  1. Ask your partner for the A record address from Hostinger’s control panel (hPanel). It’s a number like 123.45.67.89. Use the one he gives you, not one from a search.
  2. Log in to Porkbun Domain Management. Open DNS for cityoffighters.com.
  3. Write down or screenshot the current records. You’ll need them to undo this.
  4. Delete these four A records:
    • 185.199.108.153
    • 185.199.109.153
    • 185.199.110.153
    • 185.199.111.153
  5. Add one new record: Type A, Host empty, Target the Hostinger address, TTL 600. Click Add.
  6. Only if your partner gives you a different value for www, change the www CNAME to it. Otherwise leave it.

Step 3: your partner finishes

  1. When the new records are visible, usually within minutes but sometimes up to 24 hours, he turns on SSL and Force HTTPS in hPanel.
  2. The site can show a security warning until the certificate is ready. That’s normal for a short time.

Step 4: check it together

☐cityoffighters.com and www.cityoffighters.com open with a padlock
☐The Leaderboard shows your data
☐The Control panel logs in; Players, Sponsors and Stream open
☐OBS shows the overlay, and a new sponsor appears within 10 seconds
☐The phone app opens and the Events tab shows your events
☐The test winner email arrives

If something goes wrong

In Porkbun, delete the Hostinger A record and add the four GitHub A records from Step 2 back. The site returns to GitHub. This only works while GitHub Pages is still on, so don’t switch GitHub off until every check passes.

Step 5: after it’s been working for a few days

  1. Your partner’s Claude removes the domain from GitHub Pages and turns Pages off (it asks first).
  2. Keep the GitHub repo. It holds the code, and the job that stops Supabase from pausing. If you delete it, the database can pause and take the whole app down.
  3. Your partner’s Claude lists what to remove from the old project: player emails, photos and the start.gg key. Approve it first. Never delete the old project, because Iron Fist Academy is in it.
  4. Keep it public until the PC app downloads have been moved, or the download links stop working.

What stays where

DomainPorkbun. Keep auto-renew on. It renews on 6 November each year.
Website filesHostinger, updated automatically from GitHub.
Code and backups of itGitHub, and the CityOF APP files folder.
Database and server functionsThe new Supabase account.
EmailThe same Gmail, with its secrets in the new Supabase project.
Calendar and resultsstart.gg. Nothing changes.
