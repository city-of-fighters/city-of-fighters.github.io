Setup checklist · 6 November 2026

Connect email and start.gg

What’s left to switch everything on, in order. Parts 1 to 3 need the master start.gg account: the one that runs the City of Fighters hub. Part 4 needs a Gmail account. Tick each box as you go.

the token, client secret and app password are like passwords. Paste them only where a step says. Never in a chat, an email, GitHub or on stream.

What goes where

PlayersTheir own start.gg account. Password stays on start.gg. We keep gamer tag, team, start.gg user number, joined events and a 90-day login session.

ResultsLive in Supabase; official copy on start.gg.

Part 0: update the database

Needed for player logins. Safe to run again: it keeps your players, tournament and password.

  1. Open the file: city-of-fighters.sql on GitHub. Press the copy-file button.
  2. Open the Supabase SQL Editor, paste it and press Run. It should say “Success”.

Part 1: start.gg token (fills the calendar, sends results)

  1. Log in to start.gg with the master account.
  2. Profile picture → Developer Settings → Personal Access Tokens → Create new token. Name it “City of Fighters” and save.
  3. Copy it straight away: start.gg shows it only once. It lasts one year; put a reminder in your calendar to make a new one.
  4. Open the Control panel, go to the start.gg box, paste it under API key, leave the link empty and press Connect.

Check: the box says “API key saved”, and your upcoming City of Fighters events appear in the Events tab. If they don’t, press ↻ Get events from start.gg now.

Part 2: Log in with start.gg (players)

  1. On start.gg, open the developer portal in Developer Settings and create an OAuth application.
  2. Set the redirect URL to exactly: https://city-of-fighters.github.io/events.html
  3. Copy the Client ID and Client Secret.
  4. Open Supabase Edge Function Secrets and add SGG_CLIENT_ID and SGG_CLIENT_SECRET with those values.
  5. Open Supabase Edge Functions → Deploy a new function → Via editor. Name it exactly cof-startgg.
  6. Paste the code from cof-startgg/index.ts and deploy.
  7. In that function’s settings, turn Verify JWT off. Players don’t have Supabase logins, so it won’t work with this on.

Check: the Events tab now shows Log in with start.gg. Log in with any start.gg account, then press Participate on an event. Either it says “You’re in”, or start.gg’s sign-up page opens to confirm. Both are fine.

Part 3: link a tournament (players and results)

Do this for each tournament.

  1. On start.gg, create the tournament with one Tekken event and a bracket of the same type as here.
  2. Copy the event’s link (it contains /tournament/…/event/…).
  3. In the Control panel, create the tournament. In the start.gg box paste the link, leave the key empty, and press Connect.
  4. Keep the Control panel or Stream tab open on a computer: new sign-ups appear within 3 minutes, in start.gg’s seeding.
  5. When sign-up closes, press Start tournament here and Start on the bracket in start.gg.

Check: finish one test match. Within seconds the result shows on the start.gg bracket, and the box shows “results sent: 1”. Do this on a test tournament first.

results are matched by the two players, so both brackets must pair the same people. If they differ, the box says which match to report by hand on start.gg.

Part 4: winner email

Sends the champion their winner banner once, when a tournament ends.

  1. Pick the Gmail account to send from. Turn on 2-Step Verification.
  2. Create an App password and copy the 16 letters.
  3. In Supabase Edge Function Secrets add GMAIL_USER (the Gmail address) and GMAIL_APP_PASSWORD (the 16 letters).
  4. In Supabase Edge Functions deploy a new function named exactly cof-winner-email with the code from cof-winner-email/index.ts.
  5. Turn Verify JWT off for it too.

players who sign up on start.gg have no email in the app yet, so the banner can’t reach them. For now add the champion’s email in the Players tab, or ask for the app to copy emails from start.gg (start.gg shares them with tournament admins; this still has to be built).
