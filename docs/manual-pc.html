PC App Manual

This manual explains how to run a tournament from a computer. Everything here also works in a browser at https://cityoffighters.com. On a computer, that address opens the Control panel. OBS has its own manual.

1. Install and open

  1. Open https://cityoffighters.com/settings.html and open Get the apps. Download the Windows installer, or the Linux file.
  2. On Windows, open the file. If Windows says it protected your PC, click More info, then Run anyway. Click Next until Finish.
  3. Open City of Fighters. Choose whether it may save your login, type the admin password and press Unlock.

You stay logged in for 24 hours. 3 wrong passwords lock the login for 15 minutes.

2. Finding your way around

Control panelCtrl + 1. Run the tournament: create it, seed it, start it, enter results.
PlayersCtrl + 2. Add and edit players, teams and photos.
StreamCtrl + 3. Choose what OBS shows, and control cameras.
SponsorsCtrl + 4. Add or delete sponsor logos.
SettingsCtrl + 5. Things you set rarely: start.gg, calendar, test email, past tournaments, downloads.

The same tabs are at the top of every page. Ctrl + R reloads a page. The View menu has full screen and zoom. If the keys don’t work, update the app (see the OBS manual, section 9), or use the tabs.

3. Run a tournament, start to finish

Step 1: Create it on start.gg

  1. In the Control panel, click Create a new tournament on start.gg. It opens start.gg’s own page.
  2. Fill in what start.gg asks for, and add one event with its date, time and bracket type:
    • Double elimination: out after losing twice. The usual choice.
    • Single elimination: out after one loss. Fast.
    • Round robin: everyone plays everyone. A win is 3 points.
    • Swiss: several rounds; players with the same points meet. Good for big groups.
  3. That’s all. It appears in the Events calendar by itself. The Control panel notices it within 5 minutes.

start.gg doesn’t let apps create tournaments, so this is the only step done there. You make it once and never type it into the app.

Step 2: Players sign up

Players sign up for the event on start.gg, or tap Participate in the app’s Events tab.

Step 3: Start it on the day

  1. On the day of the event, it shows at the top of the Control panel with a Start tournament button.
  2. Click it. A popup shows the number of players and the bracket type. Click OK.
  3. The app creates the tournament, brings in everyone signed up with start.gg’s seeding, and makes the bracket.
  4. When test mode is off, also press Start on the bracket on start.gg, so results can be sent there.

starting replaces the players and results of whatever is set up in the app. A finished tournament is saved under Past tournaments first; an unfinished one isn’t. If a tournament is running, finish or end it first.

Someone signing up late, a walk-in, or different seeding? Press Reset bracket right after starting. The players stay. Add people in the Players tab, change the order with the arrows or Shuffle seeds, then click Start tournament in the Players box. Do this before any match is played, because it deletes results.

Step 4: Play the matches

  1. Ready to play lists matches that can start. Click Put on stream on one.
  2. Score it in the Control panel or on the phone. One match is first to 2 games; one game is first to 3 rounds.
  3. When it ends, the winner moves on by themselves. Put the next match on stream.

Step 5: Finish

  1. When the last result is in, the podium appears on stream by itself.
  2. The Control panel shows a results picture. Click Download PNG to save it.
  3. The champion is emailed their banner if the email is set up and they have an email in the Players tab.
  4. The tournament is saved under Past tournaments.
  5. Click End tournament when you’re done.

Reset bracketDeletes the bracket and results but keeps the players.
End tournamentThe app then says no tournament is in progress.
Undo last actionSteps back through your recent actions on this computer.
ReopenIn Finished matches: undoes a finished match.
Take off streamRemoves the match from the scoreboard.
Go live / End streamStarts or stops the Twitch stream, after asking you to confirm. The Stream tab must be open and connected to OBS.
Email the winner bannerSends the banner to the champion again.
Log outIn the Tournament box. Use it on shared computers.

5. Players tab

  1. Type the gamer tag, and optionally a team and email. Click Add player.
  2. To add a photo, choose a picture. It’s cropped to a square from the top by itself and shows on stream.
  3. Click Edit to change someone, even after the bracket has started. Remove photo deletes the photo.
  4. Remove takes a player out. It’s only available before the bracket starts.

Players without a photo show just their name, never an empty box.

Player card: portrait and 5 titles

Click Edit on a player. Under Player card, upload a cut-out portrait (PNG or WebP) with a see-through background. It saves at once, and empty space around the person is cut off by itself. The portrait also becomes their photo on the scoreboard, winner screen, podium and winner email, unless they have their own photo. Any player can use any title: under Showing on the card, pick up to 5 and press Save titles. Anyone who has logged in with start.gg is listed under Logged-in players; press Titles next to their name to set their portrait and titles without adding them to a tournament. They can also choose their own 5. The card stays with the gamer tag between tournaments, so the name must match the player’s start.gg gamer tag.

6. Sponsors tab

  1. Type the sponsor’s name and choose a logo (PNG, JPEG or WebP). A PNG with a see-through background looks best.
  2. Click Add sponsor. It appears on stream within about 10 seconds.
  3. Click Delete to remove one.

Logos show bottom right on the stream, one at a time, each for 4 seconds. You can have up to 30.

7. Stream tab

Choose what viewers see, check it in the preview, then press Deploy to OBS. The OBS manual explains this and the camera controls.

8. Settings tab

start.gg

  • Test mode is on by default. The app reads from start.gg (calendar, players) but sends nothing. Your tournaments on start.gg aren’t touched.
  • Untick it only for a real tournament, after a private test. Results then go to start.gg within seconds, while the Control panel or Stream tab is open.
  • API key: paste the token once and press Connect. It lasts one year.
  • Event link: normally not needed, because Start tournament links the event by itself. Use it only to link an event by hand.
  • Get players from start.gg does it at once. Otherwise it runs every 3 minutes until the bracket starts.
  • Disconnect removes the link. Anything already on start.gg stays there.

Events calendar

  • Get events from start.gg now updates the calendar. It also updates every 30 minutes while a page is open.
  • Add an event adds one by hand. Edit or delete it any time.

Test the winner email

Type an address and press Send test email. It sends a sample banner to check that Gmail is connected.

Past tournaments

Lists finished tournaments, with Delete for each. Only names and results are kept, never emails.

Get the apps

Download links for the PC app, and how to get the phone app.

9. If something goes wrong

“Too many wrong passwords”Wait 15 minutes. Or in the Supabase SQL Editor run delete from public.cof_attempts;
Scored the wrong playerUndo last action. For a finished match: Finished matches → Reopen.
Page looks oldPress Ctrl + R.
“Run the updated database file”Supabase → SQL Editor → paste all of supabase/city-of-fighters.sql → Run. It keeps your data.
Results not on start.ggCheck Settings: test mode must be off, and the box lists any problems. Press Start on the start.gg bracket too.
Change the admin passwordSee the “Connect Email and start.gg” PDF, or ask whoever manages the database.
