📲 Get the apps (computer and phone)

Computer: the control panel and Stream tab in their own window. It always shows the latest version.

Windows installer (.exe) Windows portable (.exe, no install) Linux (AppImage)

Windows may say “Windows protected your PC” because the app is not signed: click More info → Run anyway. On Linux, make the AppImage executable (right-click → Properties → Allow executing) and open it.

Phone: open the app on your phone and tap Install app (or the browser menu ⋮ → Install / Add to Home screen). It gets its own icon and opens full-screen.
